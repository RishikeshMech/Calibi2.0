4. INFERRED CURRENT UX PATTERNS (from structure, since this scan
   is text/content-based and did not capture live CSS/pixels)
------------------------------
- Standard SaaS/agency template shape: sticky-style hero -> logo/trust
  bar -> feature grid -> case-study carousel -> numbered process ->
  consultation CTA block -> testimonial carousel -> FAQ accordion ->
  footer.
- Heavy reliance on numeric proof points (85%, 70%, 3x, 60%, 10x,
  48 hours, 200% ROI, 6x, before/after metric pairs) — this is a core
  conversion device for the brand; the new theme should give these
  numbers strong visual emphasis (large numerals, contrast color,
  maybe animated count-up) rather than bury them in body text.
- Repeated 3-step "process" motif appears twice (Home + Services)
  with different labels — an opportunity for a single reusable
  timeline/stepper component in the new design system.
- Two carousels on the homepage (case studies + testimonials) —
  make sure the new theme carries over working prev/next controls,
  not just static cards.
- FAQ accordion pattern — confirm each item expands to an answer in
  the live site; the redesign should preserve the accordion
  interaction, not just the questions.
- Multiple CTA touchpoints funneling to the same action ("Book a
  Free Consultation" / "Schedule Your Free Consultation" / "Schedule
  a call with our team") — keep this repetition; it's a deliberate
  conversion pattern, just re-skin the buttons.

6. THEME DIRECTIONS TO CONSIDER (visual layer only — content unchanged)
------------------------------
Given the brand is "premium," "enterprise-grade," B2B AI automation,
three directions that typically work well without touching copy:

A) Dark "AI-native" theme
   - Near-black background (#0A0A0F–#111116), soft gradient mesh or
     particle/grid backdrop behind the hero
   - One accent (electric blue, violet, or teal) reserved for CTAs,
     stat numbers, and active states only
   - Glass-panel cards (subtle blur + 1px border) for the 7 service
     cards and case-study cards
   - Large, confident sans-serif for numerals (stat call-outs) to
     make the 85%/70%/3x proof points pop

B) Clean enterprise light theme
   - White/off-white background, one strong brand color for CTAs and
     section eyebrows, dark charcoal text (avoid pure black)
   - Card-based grid with soft shadows instead of borders
   - Editorial-style large type for H1s, tighter type for the dense
     bullet lists so the page doesn't feel text-heavy

C) Warm "practical AI" theme (matches the "practical, human, clarity"
   language from the Story page)
   - Off-white/cream base, one warm accent + one cool accent
   - Rounded corners, friendlier iconography, softer shadows
   - Good fit if the brand wants to feel less "generic AI startup"
     and more approachable for the Academy/education audience

Whichever direction, keep the SAME section order and SAME copy — this
brief is written so you (or another AI/design tool) can restyle
components without needing to re-derive the content.
